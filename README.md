## Less waiting. More watching.

Find a video, tap **Stream**, and start watching while the download continues. Usenet Player by K.A.Y. brings downloading, playback and your personal video collection into one dark, straightforward Android app.

| Feature | What you get |
| :--- | :--- |
| ▶ **Watch while downloading** | Play supported videos as data arrives, with buffering when more data is needed. |
| 🔎 **Usenet search** | Eweka / Plus integration, NZB import and compatible index configuration. |
| 🎬 **Built-in playback** | MP4, MKV and AVI playback paths, including a VLC-based AVI player. |
| ⛶ **Turn for fullscreen** | Rotate into landscape to focus on the video; rotate back to restore the download and TV controls. |
| ▤ **Your video library** | Find your app videos and ongoing streams in one dedicated tab. |
| ≡ **Make it a playlist** | Create, rename and reorder playlists. Add or remove videos and play the next item automatically. |
| 🎵 **Your music collection** | Save albums and tracks, read embedded artist/album/title tags, and play album tracks in order. |
| 📚 **Books & PDFs** | Store your reading collection. Read PDF, EPUB and text in the app, or open other book formats with a compatible reader. |
| 🖼️ **The right artwork** | Use embedded covers first, then conservative online matches. Choose a different match or edit metadata when needed. |
| 📦 **Whole-season archives** | Each episode gets its own growing file. Start episode one while later archive parts continue downloading, when archive layout allows it. |

## Get started

1. **[Download the latest APK](https://github.com/kayzaa/Usenet-Player/releases/download/v0.1.5/Usenet-Player-by-KAY-v0.1.5.apk)** onto your Android phone.
2. Open the APK and allow installation from your chosen browser or file manager if Android asks.
3. Open the app settings and enter your own Usenet provider credentials. Eweka is preconfigured with **TLS on port 563**.
4. Connect search or import an NZB, then choose **Download** or **Stream**.

**Already using the app?** Install this APK over your existing installation to update it. There is no need to uninstall first.

**Playlists:** Open **Medien → Videos → Playlisten (Playlists)**, create a list, and add videos from your library. Use the previous/next buttons during playback, or let the playlist advance automatically.

## What's new in v0.1.5

- **Music:** separate album and track views, local import, tag metadata, embedded album art and ordered album playback.
- **Books:** a dedicated PDF/ebook library, PDF pages and EPUB chapters, remembered reading position, and external-reader support for other stored book formats.
- **Covers:** embedded music/EPUB art, PDF previews and matching through Cinemeta, MusicBrainz / Cover Art Archive and Open Library. Ambiguous artwork is left for you to choose.
- **Season streaming:** extract multiple media files from the same archive and build an episode-ordered playlist that grows as more entries arrive.
- **Passwords:** NZB password metadata, NFO hints, an encrypted password list and per-archive input. RAR5 encrypted headers and Unicode passwords are supported by the new RAR decoder.

**Where to find it:** open **Medien (Media)**, then **Videos**, **Musik (Music)** or **Bücher / PDF (Books)**. Password settings are under **⋮ → Archivpasswörter**.

## A few useful details

- **Android 8.0 or newer.** The current app interface is in German; search and showcase language options are separate.
- Bring your own Usenet account and search access. No movies, NZB collection or provider subscription are included.
- Playback during download depends on the file, archive structure, codecs and available articles. Some files need more data before they can start.
- Growing AVI playback currently starts at the beginning and does not offer seeking. PAR2 repair is not included yet.
- Casting requires the phone and TV to be on the same Wi-Fi network and the receiver to support the video's container and codecs. An AVI playing locally does not guarantee that it can be cast.
- The media library contains files managed by this app. You can explicitly import music and books; it does not silently scan your whole phone.
- Password discovery uses available NZB/NFO hints and passwords you save. Unknown archive passwords cannot always be found.
- Password-protected PDFs need Android 15+ in the built-in reader; on older devices, use a compatible external reader.
- Whole-season streaming depends on where episode one occurs in the archive. Missing parts still have to arrive before they can be read.
- For archive jobs created by an older version, use **Alle Archivdateien entpacken** in Downloads to extract the remaining media from the saved source parts.
